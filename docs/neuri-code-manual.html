1. Project Overview

Purpose

Neuri is a comprehensive health diary application designed specifically for families to track the daily health status of children, with a particular focus on seizure monitoring, emotional states, and symptom tracking. The application provides a warm, child-friendly interface with multilingual support.

Target Users

  • Primary: Parents and caregivers of children with health conditions
  • Secondary: Healthcare professionals reviewing patient data
  • Tertiary: Children who can self-report (age-appropriate interface)

Core Objectives

📊 Health Tracking

Comprehensive daily logging of emotions, symptoms, seizures, and observations

🎯 Pattern Recognition

AI-powered analysis to identify trends and correlations in health data

📱 User Experience

Intuitive, child-friendly interface with accessibility features

🌍 Multilingual

Full support for Spanish and English languages

📈 Reporting

Medical-grade reports for healthcare provider consultations

👥 Multi-Profile

Support for multiple children in a single family account

13. Troubleshooting

Common Issues

🔧 Translation Keys Not Displaying

Problem: UI shows "entries.title" instead of translated text.

Solution: Ensure LanguageProvider wraps the entire app and translation keys exist in both language dictionaries.

📅 Dates in Wrong Language

Problem: Dates show in Spanish when English is selected.

Solution: Use getLocaleFromLanguage() helper and pass locale to formatDisplayDate().

👥 Profile Switching Issues

Problem: Data doesn't update when switching profiles.

Solution: Ensure active profile ID is stored in localStorage and DiaryContext refreshes on profile change.

Debug Tools

// Enable debug logging localStorage.setItem('neuri-debug', 'true'); // Check current profile console.log('Active profile:', localStorage.getItem('neuri-active-profile')); // View stored entries console.log('Entries:', localStorage.getItem('neuri-entries-demo-user-default'));
